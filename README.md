# Apollo I.O - Landing Page

Projeto desenvolvido como prática para avaliação (AV1).

🔗 **Live Demo (GitHub Pages):** [https://helgalo.github.io/lading_page_exemple/](https://helgalo.github.io/lading_page_exemple/)

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Vanilla)
- Design Responsivo (Mobile-first)
- Layout flexível com Flexbox e Grid

## 📌 Requisitos Atendidos
- [x] Cabeçalho com logo e menu alinhados (Flexbox)
- [x] Seção de destaque (*hero*) com título, texto, botão e imagem fluida
- [x] Seção de serviços em cartões (empilhados no celular, lado a lado no desktop)
- [x] Seção sobre com imagem responsiva
- [x] Rodapé informativo
- [x] Meta-tag `viewport` configurada
- [x] CSS desacoplado em `style.css` (sem estilos inline)
